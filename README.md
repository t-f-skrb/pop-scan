# POPスキャン 導入手順

値札にスマホをかざすだけで、JANと一緒に商品名・規格・売価も読み取ってリスト化するWebアプリです。文字の読み取りはスマホの中で行うので、APIキーや利用料は不要です。ホーム画面に追加すると、普通のアプリのように全画面で使えます。

## 同梱ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| zxing.min.js | バーコード読み取りライブラリ |
| ocr フォルダ | 値札の文字を読み取る仕組み(Tesseract.js と日本語・英数字の学習データ) |
| manifest.webmanifest | アプリ名・アイコンなどの設定 |
| sw.js | オフラインでも起動できるようにする仕組み |
| icon-192.png / icon-512.png / apple-touch-icon.png | アイコン |

## 1. インターネットに公開する(GitHub Pages・無料)

カメラを使うには、`https://` で始まるアドレスで公開する必要があります。ここではGitHub Pagesを使う方法を説明します。

1. https://github.com で無料アカウントを作ります。
2. 右上の「+」→「New repository」を選び、名前(例:`pop-scan`)を入れ、**Public** を選んで「Create repository」を押します。
3. 作成直後の画面で「uploading an existing file」を押し、このフォルダの中身を**すべて**ドラッグして、「Commit changes」を押します。`ocr` フォルダも、中のフォルダ構成を保ったままアップロードしてください(フォルダごとドラッグすれば構成が保たれます)。
4. リポジトリの「Settings」→ 左メニューの「Pages」を開きます。
5. 「Branch」で `main` と `/ (root)` を選び、「Save」を押します。
6. 1〜2分待つと、画面上部に `https://ユーザー名.github.io/pop-scan/` のようなアドレスが表示されます。これがアプリのアドレスです。

※ Publicのリポジトリなので、アプリのプログラムは誰でも見られます。ただし、読み取ったリストや商品マスタは各スマホの中にだけ保存され、公開されることはありません。商品マスタのCSVはGitHubにアップロードしないでください。
※ Netlify や Cloudflare Pages など、https で公開できる他のサービスでも動きます。

## 2. スマホにインストールする

- **iPhone**:Safariでアドレスを開き、共有ボタン →「ホーム画面に追加」
- **Android**:Chromeでアドレスを開き、メニュー(︙)→「ホーム画面に追加」または「アプリをインストール」

初回の「スキャンを開始」で、カメラの使用許可を求められるので「許可」を選んでください。

## 3. 使い方

- **かざして自動追加**:値札全体を黄色い枠に入れてかざすと、ピッという音とともにJANがリストに追加されます。続けて、値札の文字から商品名・規格・売価が1〜3秒ほどで自動入力されます。同じ値札を続けて読んでも、二重には登録されません。
- **確認してから追加**:読み取るたびに確認画面が開き、読み取った商品名などを直してから追加できます。
- **写真から読み取る**:撮った写真から読み取ります。値札が1枚だけ写っている写真なら、商品名・規格・売価も読み取ります。
- **CSVを書き出す**:「JANコード・商品名・規格・本体価格・税込価格」の列で書き出します。Excelで開いてもJANが指数表示に化けない形式です。iPhoneでは共有メニューが開くので、「ファイルに保存」やメール・LINEなどで送れます。
- **ライト**:Androidの対応機種では、暗い売場でライトを点けられます。

**文字の読み取りについて**
- 初めてスキャンを開始したときに、文字認識の学習データ(約13MB)を読み込みます。Wi-Fiのある場所で一度開いておくと安心です。2回目以降はすぐに使えます。
- 読み取り精度は、写り方で大きく変わります。値札が枠いっぱいに、正面から、ピントが合って写るようにかざしてください。
- 商品名の一部の文字や、税込価格が読めないことがあります。特に価格は、書き出す前に一覧で確認してください。確認モードを使うと、その場で直せます。
- 文字の読み取りが不要な場合は、「設定」→「値札の文字も読み取る」をオフにしてください。JANだけを素早く読み取れます。

## 4. 商品マスタで正確に自動入力する(任意・無料)

商品マスタのCSVを読み込んでおくと、かざしたJANに対応する商品名・規格・売価がマスタから入ります。マスタにある商品は、値札の文字の読み取りより正確です。マスタにない商品だけ、値札の文字から読み取ります。

1. JAN・商品名・規格・本体価格・税込価格の一覧を、CSVで用意します。店舗や本部の商品マスタから書き出したもので構いません。
2. アプリの「設定」→「商品マスタ」→「CSVを読み込む」で、そのファイルを選びます。
3. 「○件を読み込み済み」と表示されれば完了です。以後、読み込んだマスタはスマホに保存されます。

**CSVの注意点**
- 1行目に見出しがあれば、「JAN」「商品名」「規格」「本体」「税込」などの列名から列を自動で判別します。見出しがない場合は、「JANコード・商品名・規格・本体価格・税込価格」の並びとみなします。
- Excelで保存した日本語のCSV(Shift_JIS)も、UTF-8のCSVも読み込めます。
- JANが「4.96E+12」のような指数表示で保存されていると読み込めません。Excelで列の表示形式を「数値(小数点以下0桁)」か「文字列」にしてから保存し直してください。
- マスタにないJANは、値札の文字から読み取ります(設定でオフにしている場合はJANだけ追加されます)。
- 売価を変更したときは、新しいCSVを読み込み直すと、マスタ全体が置き換わります。

## 5. データについて

- 読み取ったリストと商品マスタは、そのスマホのブラウザの中に保存されます。アプリを閉じても消えません。
- ブラウザの履歴やWebサイトデータを消去すると、リストも消えます。作業が終わったらCSVを書き出しておいてください。
- 複数のスマホ間でリストは同期されません。それぞれのスマホでCSVを書き出してまとめてください。

## 6. アプリを更新するとき

GitHubのリポジトリで `index.html` などを新しいファイルで上書きアップロードすると、次にアプリを開いたときから反映されます。反映されない場合は、アプリを一度完全に閉じてから開き直してください。
